# SheetReader · 六线谱自动滚动阅读器

上传某首歌的多张吉他六线谱图片，自动合并为连续长谱；演奏时曲谱根据演奏进度**自动向下滚动**，
不用手动翻页和滑动，解放双手。

纯前端实现（原生 HTML / CSS / JS，无框架、无构建、无后端），数据保存在浏览器 IndexedDB 中。

## 功能

- **曲谱库**：新建歌曲、管理已有曲谱、删除；封面与页数自动生成
- **多图上传**：点击或拖拽一次上传多张谱图（PNG / JPG 等）
- **拖拽排序**：拖动缩略图调整页序，编号 `1、2、3…` 常显并随拖拽**实时更新**
- **页管理**：单页顺时针旋转 90°（纠正手机拍照方向）、删除单页、歌名/歌手随时修改
- **导出合并长图**：把多页谱真正合并成一张长 PNG 下载
- **移动端适配**：支持 iPhone 安全区、横竖屏与动态视口，针对 11/13 英寸 iPad 优化布局和触控尺寸
- **自动滚动演奏**：
  - 多页图片无缝拼接为一张连续长谱
  - 根据歌名和歌手自动查询原版 BPM，查询成功后写入 IndexedDB；默认按原版速度，可单独设置练习速度
  - BPM 查询接口通过 `window.SHEETREADER_BPM_API` 配置，支持自定义接口地址、请求头和响应字段
  - 固定**播放指示线**与半透明粉色当前小节提示
  - 曲谱正文按 BPM 缓慢滚动，页间留白快速平滑掠过
  - 底部速度倍率 `0.25×–3×` 实时控制曲谱滑动速度，并自动记住上次设置；支持进度条拖动和点击谱面跳转
  - 鼠标滚轮、拖动滚动条或单指拖动谱面均可快速、平滑地改变播放进度，并从新位置继续
  - 当前视觉尺寸显示为 `100%`（实际宽度保持不变），最小可缩放至 `10%`

## 播放器快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `+` / `-` | 滚动加速 / 减速 |

## 运行

方式一（推荐）：本地 HTTP 服务打开，保证 IndexedDB 在所有浏览器可用：

```bash
cd sheetReader
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

方式二：直接双击 `index.html`（Chrome / Edge 支持本地文件的 IndexedDB）。

第一次使用可以点击曲谱库中的「**载入示例曲谱**」，零素材体验完整流程。
